# BharatSafe

A dependency-free responsive landing page for BharatSafe, a smart emergency QR identity brand for bikes, cars, and luggage.

## Run

Open `index.html` in a browser. No build step or package installation is required.

## Included

- Responsive editorial landing page inspired by the supplied Subscrr reference
- BharatSafe messaging adapted from the public bharatsafes.com product positioning
- Interactive bike, car, and luggage tag selector
- FAQ accordion and smooth section navigation
- Product mockup built with HTML and CSS
- Public journal at `blog.html`
- Local admin journal manager at `admin.html`
- Blog posts persist in browser `localStorage` and can be drafted, published, edited, or deleted
- No API keys or backend required for this visual prototype

## Blog workflow

Open `admin.html` to write and publish stories. Published stories appear on `blog.html`, which is linked from the homepage footer. This admin panel is intentionally local-only for the static prototype; add authentication and a database before deploying it publicly.
